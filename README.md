# Wheel of Time Game

Browser games set in the world of the Wheel of Time.

- [`aes-sedai-rpg/`](aes-sedai-rpg/): **The Wheel Weaves: Aes Sedai**, a top-down action RPG. Rise from Novice to Aes Sedai, weave the Five Powers, choose one of seven Ajah classes, navigate Tower politics and a coup, and survive the over-channeling engine. Plain HTML5 canvas and vanilla JavaScript with no dependencies.

```bash
cd aes-sedai-rpg && python3 -m http.server 8000
# then open http://localhost:8000
```
